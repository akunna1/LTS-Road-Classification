# Level of Traffic Stress (LTS) Road Classification & Bike Lane Recommendations 🚴‍♂️🛣️

## Overview

This project analyzes the road network of Chapel Hill, NC to classify streets by their Level of Traffic Stress (LTS) for cyclists. Using R and ArcGIS Pro, the analysis identifies safer, low-stress routes and suggests strategic bike lane additions to improve cycling safety and accessibility.

The ultimate goal is to support safer cycling infrastructure, assist UNC’s Department of City and Regional Planning, and help reduce demand for limited campus parking. 🎯

---

## Features

* Classified Chapel Hill road network by LTS using key factors such as:

  * Lane count
  * Number of intersections
  * Traffic flow volume

* Created vector layers in ArcGIS Pro visualizing:

  * Low-stress bike-friendly routes 🚲
  * Recommended locations for new bike lanes 🛤️

---

## Purpose

* Promote cycling safety and encourage low-stress routes for all rider types
* Provide actionable bike lane recommendations to city planners
* Support UNC’s sustainability goals by reducing campus parking demand ♻️

---

## Tools & Technologies

* **R:** Data processing, LTS classification calculations, and data visualization 📊
* **ArcGIS Pro:** Geospatial mapping, vector layer creation, and spatial analysis 🗺️

---

## Usage

1. Load and preprocess road network data in R
2. Perform LTS classification based on roadway and traffic characteristics
3. Export classified data to GIS for mapping and visualization
4. Use ArcGIS Pro to create bike lane recommendation layers and maps
